# UseSendra
Overview

Sendra is a multi-channel conversational agent that enables users to buy, sell, send, and receive dollar-denominated stablecoins (USDT, USDC and more) directly within chat interfaces, starting with WhatsApp and expanding to USSD.

Without installing new apps or learning complex crypto workflows, users can perform everyday financial actions using simple text, images, or voice notes. Sendra abstracts away wallets, bridges, and third-party on/off-ramp friction, delivering seamless access to stablecoins
